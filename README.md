# ⌚ Awesome Watch Collection

> An open, community-built library of watch knowledge: mechanical, automatic, quartz, digital, smart and hybrid,
> organised from **First Wind** (beginner) to **Grande Complication** (pro).

🚧 **Status: planning (Phase 0, "Mainspring").** See the full [Master Plan](PLAN.md).

## Learning Paths

| Level | Name | For |
|---|---|---|
| 💎 | **First Wind** | Beginners: anatomy, types, specs, your first watch |
| 💎💎 | **Automatic** | Intermediate: how movements work, brands, building a collection |
| 💎💎💎 | **Complication** | Advanced: finishing, certifications, vintage, market |
| 💎💎💎💎 | **Grande Complication** | Pro: escapements, tourbillons, watchmaking, auction-level research |

## Sections

- **Mechanical**: manual-wind, automatic
- **Quartz Analog**: standard, HAQ, solar, kinetic, radio and GPS
- **Digital**: LCD, LED, ana-digi, rugged
- **Smartwatch**: full OS, fitness, outdoor multisport
- **Hybrid**: hybrid-smart, Spring Drive, mecaquartz
- **Exotic**: tuning fork, jump hour, wandering hour, concept pieces
